================================================================================
  NOTES
================================================================================
 
  1. Always activate the venv before running any command.
     Without activation, Python will not find the project packages.
 
  2. The --subset all flag trains sequentially on FD001, FD002, FD003, FD004
     in that order. Expect approximately 5-15 minutes per subset per model
     depending on hardware.
 
  3. XAI files (gradientshap.py, integrated_gradients.py, attention_viz.py)
     and evaluation files (xai_metrics.py) have NO standalone CLI.
     They are imported and executed exclusively through their corresponding
     Jupyter notebooks (07, 08, 09, 10).
 
  4. All results are saved automatically to:
       checkpoints/   — best model .pt files
       results/       — JSON result files per model per subset
       figures/       — PNG plots generated by each notebook
 
  5. Random seed is fixed at 42 throughout. Re-running any command will
     produce identical results to those reported in the dissertation.
